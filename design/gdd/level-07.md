## 1. 概述

第七关把箱子从“移开障碍”升级为“制造道路”。玩家依次遇到两条一格宽的沟：
第一只箱子向右推入横向沟，第二只箱子向上推入纵向沟。箱子落在低一格的沟底后，
顶面与道路齐平，成为玩家能够滚过的桥面。

两次填沟方向不同，而且第二条沟位于第一条沟之后，因此两只箱子都不可绕过。

## 2. 玩家感受

第一只箱子掉入沟中时，玩家会先担心自己失去了箱子，随后发现箱子顶面正好补齐道路。
第二只箱子出现在转向后的新沟前，要求玩家把刚学到的用途迁移到另一个方向。完成两次
填沟后，玩家理解箱子既可以是障碍，也可以成为永久地形。

布局约束：

- 第一段道路为 `(0,0) → (2,0)`，第一条沟位于 `(3,0)`。

- 箱子落地后顶面必须与 `y=+0.00` 道路齐平。
- 两只箱子的侧面没有可站立格，推动前不存在错误方向的站位。
- `E` 位于终点草地区内部 `(6,5)`。

## 4. 详细规则

### 4.1 第一只箱子

玩家执行 `R PUSH(a,R)`，把 `horizontal_box` 推入 `d1`。推动结束后箱子在目标 XZ
吸附，再因无同层支撑而下落到 `(3,0,-1.00)`。箱子静止后，其顶面成为
`(3,0,+0.00)` 的可行走支撑。

### 4.2 第二只箱子

玩家跨过第一只箱子，沿道路转向上方，在 `(4,2)` 前执行 `PUSH(b,U)`。第二只箱子
落入 `d2`，形成纵向桥面。两条沟是串联关系，只填其中一条都无法到达终点。

### 4.3 下落与支撑

`DROP(d1)` 和 `DROP(d2)` 不计入玩家步数。箱子的 XZ 由推动目标格决定，Y 由物理
下落决定。箱子一旦落入沟底便不再需要移动，也不受玩家复位机制影响。

## 5. 公式与解法验证

```text
ditch_depth = 1.00
box_height = cubeHalfSize * 2 = 1.00
filled_surface_y = ditch_floor_y + box_height = 0.00
push_count = 2
primary_steps = 11

primary = R PUSH(a,R) R R U PUSH(b,U) U U R U R
```

带动态支撑的状态检查已验证：

- `d1` 未填充时，玩家无法到达 `(4,0)`；
- `d2` 未填充时，玩家无法到达终点草地区；
- 两只箱子的推动目标分别且唯一；
- 两次下落后箱子顶面连续承接标准路线；
- 标准解 11 次滚动结束于 `E`，符文方向为 `DOWN`。

物理静止位置仍须在场景搭建后重复验证，不能仅凭静态模型判定完成。

## 6. 边界情况

| 情况 | 处理方式 |
|------|----------|
| 玩家只填第一条沟 | 可到达转向道路，但被第二条沟阻断 |
| 玩家尝试绕过第一条沟 | 周围没有同高支撑，跌落并复位 |
| 箱子没有落在沟底中心 | 视为物理或碰撞体配置错误，扩大沟底稳定面但不改变格位 |
| 箱子顶面低于道路 | 玩家无法跨越，必须修正沟底高度 |
| 箱子顶面高于道路 | 箱子成为不可攀爬墙，必须修正沟底高度 |
| 玩家滚出箱桥侧边 | 正常下落并通过 `killPlaneY` 复位 |
| 玩家错误朝向进入 `E` | 不通关，可在终点草地区调整 |

## 8. 可调参数

| 参数 | 建议值 | 影响 |
|------|--------|------|
| 两处沟底深度 | 精确 `1.00` | 决定箱子顶面能否与道路齐平 |
| 沟宽 | 每处 1 格 | 每只箱子正好解决一处缺口 |
| `pushDuration` | `0.25f` | 与玩家翻滚同步 |
| 沟底碰撞面 | 略宽于 1 格视觉面但不越格 | 提高物理落点稳定性 |
