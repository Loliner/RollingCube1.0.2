## 1. 概述

第二关把第一关的平面翻滚扩展到立体空间。玩家从高台出发，沿直线滚下一个
`0.50` 单位的落差，在低台安全着陆；低台不是单格通道，而是一块带终点的开放草地，
让玩家在下落后重新观察符文并自行调整。

本关只新增“可以从高处落到低处”这一条规则，不加入开关、升降台、移动平台或箱子。

## 2. 玩家感受

玩家第一次滚出高台边缘时，会看到方块脱离运动学翻滚并自然落下。落点前方仍有充足
空间，因此下落不是惩罚，而是一次明确的空间层级变化。玩家随后发现自己仍需满足符文
朝下的终点规则，从而建立“下落后重新观察，再规划路线”的习惯。

期望情绪顺序：

**发现落差 → 安全下落 → 重新定位 → 调整朝向 → 完成贴合**

布局约束：

- 高台表面为 `y=+0.50`，只包含出生点和两格引导路。
- 低台表面为 `y=+0.00`，落点位于 `(x=-01,z=+00)`。
- 终点平台的主体为 `x=+00..+02`、`z=-01..+01` 的 `3 × 3` 草地。
- `E` 位于该 `3 × 3` 区域中央 `(x=+01,z=+00)`。
- 落点与终点相隔两格，避免玩家落地后立刻进入终点。
- 低台周围不设置可被误认为上坡路线的半高地块。

## 4. 详细规则

### 4.1 高台与下落

玩家从 `S` 连续向地图右方滚动。第三次滚动从高台边缘
`(x=-02,z=+00,y=+0.50)` 进入低层列 `(x=-01,z=+00)`，因脚下没有同高支撑而触发
`StartFalling()`。

`LandWhenSettled()` 必须让玩家稳定落在 `d1.land`，并将玩家中心高度吸附到
`y=+0.50`。落地后旋转吸附到最近的 90°，再恢复输入。

### 4.2 终点与调整空间

标准解继续向右移动。玩家第五步第一次进入 `E` 时符文朝 `RIGHT`，不会通关；第六步
离开到平台右侧，再通过 `U L D` 绕行返回中央终点，此时符文朝下。

低台允许其他合法调整路线。地图不要求玩家严格执行标准解，但任何解都必须经过声明的
下落 `d1`，最终位于 `E` 且符文面朝下。

### 4.3 反向移动

玩家落到低台后不能直接滚回高台。尝试从 `(x=-01,z=+00,y=+0.00)` 向左移动时，高
`0.50` 的相邻地形被 `GetBlockingCollider()` 判定为阻挡，玩家播放
`ShakeFeedback()`。


状态搜索已验证 `primary` 的每次正常滚动都位于 RCMap 的有效格位，终点坐标和符文
终态均正确。物理下落的 XZ 落点由 `d1` 明确；场景搭建后仍需多次 Play Mode 测试，
确认短距离竖直下落不会产生非预期侧向位移或随机翻转。

## 6. 边界情况

| 情况 | 处理方式 |
|------|----------|
| 玩家从低台尝试回到高台 | 被高差阻挡，播放抖动反馈 |
| 玩家从高台两侧滚出 | 跌入虚空并通过 `killPlaneY` 回到出生点 |
| 玩家在 `d1` 落地时发生轻微物理偏移 | 以支撑射线命中点重算 Y，并吸附 XZ 与 90° 旋转 |
| 玩家错误朝向进入 `E` | 不累计通关时间，允许从周围任意草地格离开 |
| 玩家落地后采用非标准路线 | 允许，只检查最终位置和符文朝向 |

## 8. 可调参数

| 参数 | 建议值 | 影响 |
|------|--------|------|
| 高低台落差 | `0.50` | 足够明显，同时保持短距离安全下落 |
| 高台长度 | 3 格 | 让玩家在下落前建立移动方向 |
| 低台调整区 | `3 × 3` 格 | 支持多条符文修正路线 |
| `Player.rollDuration` | `0.25f` | 基础翻滚节奏 |
| `Player.killPlaneY` | 低于最低有效地形 2–3 单位 | 避免把正常下落误判为出界 |
