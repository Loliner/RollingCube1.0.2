## 1. 概述

第二关把第一关的平面符文调整扩展到三层立体空间。玩家先向东进入高层岔路，从两个
向南下落点中选择一个进入中层；中层向西展开，并再次提供两个方向不同、但都能形成
合法解的下落点。

第二次下落不会直接压中终点。两个下落点都会把玩家送到最低层 L 型平台的同一个入口，
玩家还需向南翻滚一格进入 `E`。如果没有在中层根据所选下落方向调整符文，玩家虽然
能够抵达终点，却无法触发通关。

本关只使用基础翻滚、下落、符文朝向和终点规则，不加入开关、升降台、移动平台或箱子。

## 2. 玩家感受

玩家首先发现道路不再是一条直线，而是在高层和中层各提供两个可用的下落点。两个选择
都不是假路，但不同入口会改变玩家抵达中层时的符文状态和后续调整路线。

第一次尝试时，玩家可能沿最直接的道路进入最低层，再向南滚入 `E`，随后发现终点没有
启动。失败反馈促使玩家回想：真正需要规划的不是“能否落下”，而是“经过下落和最后
一次翻滚后，哪个符文面会朝下”。

期望情绪顺序：

**发现立体岔路 → 选择落点 → 观察符文 → 规划第二次下落 → 错误验证或成功贴合**

布局约束：

- 高层表面为 `y=+1.00`，共 5 个地块，包含通向 `d1a` 和 `d1b` 的 `2 × 2` 岔路。
- 中层表面为 `y=+0.50`，共 8 个地块，由向西主路和朝向调整区域组成。
- 低层表面为 `y=+0.00`，共 3 个地块，构成 L 型平台。
- `E` 固定在 `(x=-03,z=-03,y=+0.00)`。
- `d1a` 和 `d1b` 是高层到中层的两个合法下落点。
- `d2a` 和 `d2b` 是中层到低层的两个合法下落点。
- `d2a` 与 `d2b` 从不同方向进入同一落点 `(x=-03,z=-02,y=+0.00)`。
- 玩家从任意第二下落点着陆后，都必须再向南滚动一格才能进入 `E`。
- `(x=-04,z=-02,y=+0.00)` 是错误到达后的观察与离场格，不构成朝向调整回路。

## 4. 详细规则

### 4.1 高层双下落点

玩家从 `S` 向东进入高层岔路：

- `d1a` 从 `(x=+01,z=-01,y=+1.00)` 向南下落，落在中层
  `(x=+01,z=-02,y=+0.50)`。
- `d1b` 从 `(x=+02,z=-01,y=+1.00)` 向南下落，落在中层
  `(x=+02,z=-02,y=+0.50)`。

两条路都合法。由于到达下落点前的移动次数不同，玩家落到中层后的符文朝向也不同。
高层其他外缘没有声明的安全落点，滚出后应跌入虚空并复位。

### 4.2 中层双下落点

中层包含两个通向同一低层入口的下落点：

- `d2a` 从 `(x=-02,z=-02,y=+0.50)` 向西下落。要在随后向南进入 `E` 时符文朝下，
  玩家应在触发 `d2a` 前把符文调整为 `BACK`。
- `d2b` 从 `(x=-03,z=-01,y=+0.50)` 向南下落。要在随后向南进入 `E` 时符文朝下，
  玩家应在触发 `d2b` 前把符文调整为 `UP`。

两个下落点都能形成合法解，不存在固定的“正确洞”和“假洞”。交叉选择或采用非标准
路线时，玩家必须依据实时符文朝向自行决定是否需要继续调整。

### 4.3 最低层 L 型平台

`d2a` 和 `d2b` 都落在 `(x=-03,z=-02,y=+0.00)`。玩家落地时尚未进入终点，需要再
向南滚动至 `(x=-03,z=-03,y=+0.00)`。

未调整的直接路线可以到达 `E`，但符文不会朝下，因此停留超过两秒也不通关。玩家可以
向北返回落点，再向西进入 `(x=-04,z=-02,y=+0.00)` 观察符文或主动跌落复位。由于
最低层只有三个 L 型连接格，往返移动不能形成闭环，也不能在低层修正符文朝向。

玩家不能从最低层直接爬回中层；尝试向高 `0.50` 的相邻地形移动时应被阻挡。

## 5. 公式与解法验证

```text
upper_surface_y = +1.00
middle_surface_y = +0.50
lower_surface_y = +0.00
drop_height = 0.50

upper_tile_count = 5
middle_tile_count = 8
lower_tile_count = 3

primary_steps = 14
alternate_1_steps = 14
```

标准路线：

```text
primary =
R R D D DROP(d1b)
L L L L R U L D
L DROP(d2a) D

alternate_1 =
R D D DROP(d1a)
L L L U R D L U L
D DROP(d2b) D
```

静态朝向验证：

```text
start_rune = UP
primary_rune_before_d2a = BACK
alternate_1_rune_before_d2b = UP
primary_end_rune = DOWN
alternate_1_end_rune = DOWN
```

错误直行路线：

```text
R R D D DROP(d1b) L L L L L DROP(d2a) D
```

该路线可以到达 `E`，但结束时符文不为 `DOWN`，因此不能通关。

物理下落不应引入随机旋转。静态解法把每次下落前完成的 90° 翻滚作为朝向变化来源，
物理阶段只负责垂直落地。场景搭建后仍必须重复验证四个下落声明的 XZ 落点和稳定朝向。

## 6. 边界情况

| 情况 | 处理方式 |
|------|----------|
| 玩家选择 `d1a` | 正常落在中层左侧入口，可继续前往任一第二下落点 |
| 玩家选择 `d1b` | 正常落在中层右侧入口，可继续前往任一第二下落点 |
| 玩家选择 `d2a` | 从西侧进入低层入口，按当前符文朝向决定最终结果 |
| 玩家选择 `d2b` | 从北侧进入同一低层入口，按当前符文朝向决定最终结果 |
| 玩家未调整便进入 `E` | 不累计通关时间，允许返回观察格后复位重试 |
| 玩家在低层尝试回到中层 | 被高度差阻挡 |
| 玩家从未声明安全落点的边缘滚出 | 跌入虚空并通过 `killPlaneY` 回到 `S` |
| 物理下落产生 XZ 偏移或随机旋转 | 视为实现缺陷，不能验收 |

## 8. 可调参数

| 参数 | 建议值 | 影响 |
|------|--------|------|
| 单次落差 | `0.50` | 保持稳定短距离下落，并让三层高度关系清晰 |
| 高层地块数 | 5 格 | 提供两个可读的初次下落选择 |
| 中层地块数 | 8 格 | 提供两条第二下落路径和符文调整空间 |
| 低层地块数 | 3 格 | 保持 L 型终局，不允许在终点附近补救朝向 |
| `Player.rollDuration` | `0.25f` | 基础翻滚节奏 |
| `Player.killPlaneY` | 低于最低地形 2–3 单位 | 避免正常下落被误判为出界 |
