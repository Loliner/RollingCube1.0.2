# GDD — 开始界面（实时关卡预览）

## 1. 概述

`MainMenu.unity` 是常驻的 GameShell。左侧显示章节与关卡选择，右侧直接显示当前所选
关卡的真实 3D 内容。选择关卡只切换实时预览；玩家点击独立的“开始”按钮后，菜单淡出、
相机移到游玩构图，场景不再二次加载。

视觉结构参考既定主菜单图：左侧约三分之一为半透明导航区，右侧为关卡主体；正式美术素材
尚未接入前使用简单色块和文字占位。

## 2. 玩家感受

玩家从标题界面看到的就是即将游玩的真实世界。选关时旧关卡从玩家附近向外收缩消失，
新关卡从玩家附近向外弹性出现；确认开始只是菜单和镜头让位，不出现黑屏或额外加载等待。

## 3. 场景与数据

- `MainMenu` 始终是正常流程中的活动场景，并持有：
  - `GameFlowController`
  - 唯一的持久 `Player`
  - 唯一的主相机、主灯光和共享后处理环境
  - `MainMenu` Canvas
- 关卡场景使用 `LoadSceneMode.Additive` 加载。
- `LevelCatalog` ScriptableObject 是章节顺序、关卡顺序、场景名、显示名和预览素材的来源；
  UI 和通关推进不得再硬编码 `Chapter1_Scene1` 到 `Scene9`。
- 每个关卡场景提供一个 `LevelContext`：
  - `LevelRoot`：该关卡全部动态内容。
  - `LevelSpawn`：持久 Player 的关卡对齐锚点。
  - `StandaloneRig`：默认禁用的独立测试相机、灯光和环境。
  - 预览与游玩相机参数。
- Additive 加载时，`LevelContext.Awake` 在机关 `Start` 前平移完整 `LevelRoot`，使
  `LevelSpawn` 对齐持久 Player；Player 和相机本身不瞬移。

## 4. 导航与状态

### 4.1 章节页

- 进入 `MainMenu` 默认显示章节卡片。
- 点击章节卡片进入该章的关卡网格。
- Esc 在章节页不执行操作。

### 4.2 关卡页

- 显示返回、关卡卡片、当前选择说明和独立“开始”按钮。
- 已完成关卡显示完成标记；未解锁关卡禁用；当前选择高亮。
- Esc 或返回按钮回到章节页，不改变已经加载的实时预览。
- 点击已解锁关卡立即发起预览切换，但不会进入游玩状态。
- 连续快速点击时保留最后一次选择；正在执行的切换结束后只加载最终目标。

### 4.3 默认选择

- 优先恢复 `LevelProgress.lastSelectedLevelId`。
- 若记录不存在或已无效，选择当前最高已解锁关卡。
- 初始预览也播放关卡进入波纹。

### 4.4 开始

- “开始”仅在 `PreviewReady` 可点击。
- 点击后菜单在约 0.3 秒内淡出并略向左滑动。
- 持久相机在约 0.6 秒内从预览构图移动至游玩构图。
- 不重新加载目标关卡；镜头结束后清零 Step/Dead、恢复时间并交还 Player 控制。

## 5. 实时预览切换

- 旧 `LevelRoot` 以 Player 为中心播放 `Ease.InBack` 缩小波纹。
- 同时开始异步加载目标关卡。
- 默认在旧关卡退出开始 1 秒后启动新关卡进入；若加载尚未就绪，则等待就绪后立即进入。
- 新 `LevelRoot` 以 Player 为中心播放 `Ease.OutBack` 放大波纹。
- 旧关卡完成退出后卸载。
- 转场期间 `Time.timeScale = 0`，转场和镜头 DOTween 使用 unscaled update。
- `Application.runInBackground` 保持开启，使失焦期间的加载和转场状态机可以收尾。
- 若目标场景未注册有效 `LevelContext`，流程超时并保留/恢复可用的旧预览，同时显示错误。

具体动画规则见 [ui-seamless-level-flow.md](ui-seamless-level-flow.md)。

## 6. 存档与解锁

- 沿用 `Application.persistentDataPath/levelprogress.json` 和现有完成条目格式。
- 每章第 1 关永久解锁；其余关卡在前一关完成后解锁。
- `lastSelectedLevelId` 与完成记录一起持久化。
- 选择预览和完成后推进都会更新最后选择。
- 原有存档没有 `lastSelectedLevelId` 时按缺省值处理，保持向后兼容。

## 7. 响应式布局

- 1920×1080 为视觉基准。
- 左侧菜单固定为安全宽度并限制最大宽度，主要 3D 构图保留在右侧。
- 目标适配范围为 4:3 到 ultrawide；正式素材接入后允许替换占位图，不改变交互层级。

## 8. 验收标准

- [ ] 启动后显示章节页，右侧同时出现真实关卡预览。
- [ ] 默认预览恢复上次选择，否则为最高已解锁关。
- [ ] 章节 → 关卡为两级导航；锁定、完成、选择、加载状态明确。
- [ ] 点击关卡只切换预览，旧关先退、新关后进，并支持最后点击优先。
- [ ] 点击“开始”不会再次加载场景；菜单淡出、相机移动后即可操作。
- [ ] GameShell 始终是活动场景，正常流程中只有一个 Player、主相机和 AudioListener。
- [ ] 4:3、16:9 和 ultrawide 下菜单与关卡主体均可用。
- [ ] 既有完成进度仍能读取并正确解锁。
