**所属章节**：第一章

## 1. 概述

第三关首次教学“玩家可以通过压力开关改变场景”。玩家沿曲折的起点路线找到开关，
持续踩住一秒后，近端与远端桥面依次升起。玩家返回桥口、穿过刚刚形成的桥梁，并在
桥后从两个合法下落点中选择一条路线前往终点。

关卡只有两层参与玩法：`y=+0.00` 是开关和桥梁所在的主要路线，`y=-0.50` 是降低状态
的桥面和终点路线。`y=+0.50` 只放置无法进入的装饰高台，不参与解谜。

## 2. 玩家感受

本关的主要认知负担仍然是“发现开关—观察变化—利用变化”。桥面由近到远错峰升起，
让机关反馈具有清晰方向性。桥后双下落点提供一次轻量选择：近处下落后路线更曲折，
远处下落需要先绕行，但落地后可以直达终点。

两条路线步数相同且都能通关，不存在纯粹用于惩罚玩家的假下落点。

布局约束：

- 起点路线依次向东、向南转弯，开关不位于出生点与桥口的直线上。
- 两块桥面降低时与 `y=-0.50` 同层，升起后必须与 `y=+0.00` 主路线齐平。
- 装饰高台位于 `z=+02`，使用不可通行的 `X`，不得成为标准解或备选解的一部分。
- 过桥后的 `(x=+02,z=-01,y=+0.00)` 是路线分叉点。
- `d1` 和 `d2` 都是合法下落，不允许配置为死亡点或单向卡死区域。
- 两条下层路线在 `E=(x=+06,z=+00,y=-0.50)` 汇合。

## 4. 详细规则

### 4.1 开关教学

玩家从 `S` 执行 `R R D D L` 到达 `bridge_switch`。玩家必须持续停留 `1.0s`；
提前离开时取消本次触发，两块桥均保持低位。

开关触发后，两块桥永久升起。玩家离开开关不会令桥复位。

### 4.2 桥面错峰

`bridge_west` 在开关完成持续判定后立即启动。`bridge_east` 额外等待 `0.50s` 后启动。
两者上升距离均为 `0.50`，移动时长均为 `1.25s`，使用 `Ease.InOutSine`。

错峰表现是重叠的级联动画，而不是等待第一块完全停止后才启动第二块。玩家看到桥从
近端向远端延伸，同时总等待时间保持在三秒以内。

### 4.3 双下落路线

过桥到达分叉点后：

- `d1`：继续向右并向南下落。落地后执行 `R R R U U`，先沿下层向东，再向北转弯；
- `d2`：先向北绕到 `(x=+03,z=+01,y=+0.00)`，向南下落后执行 `R R R` 直达终点。

两条完整路线均为 17 次滚动，抵达 `E` 时符文面朝下。选择影响路线形状，但不制造
步数优劣或隐藏惩罚。

### 4.4 低桥误落

桥未升起时，玩家可从桥口误落到 `bridge_west`。由于禁用攀爬，玩家无法从低桥进入
`y=+0.00` 的出口平台；继续离开边缘后通过 `killPlaneY` 复位。低桥误落不是合法捷径。

## 5. 公式与解法验证

```text
bridge_rise = 0.50
switch_hold = 1.00s
bridge_west_delay = 0.00s
bridge_east_delay = 0.50s
bridge_move_duration = 1.25s
bridge_ready_time = 1.00 + 0.50 + 1.25 = 2.75s

primary_steps = 17
alternate_steps = 17
```

路线状态验证：

- 未触发开关时，起点区域与桥后区域不存在正常行走连接；
- `bridge_west` 必须先于 `bridge_east` 发生 Y 位移；
- 主路线通过 `d1` 落在 `(x=+03,z=-02,y=-0.50)`；
- 备选路线通过 `d2` 落在 `(x=+03,z=+00,y=-0.50)`；
- 两条路线均在第 17 次滚动后到达 `E`，符文方向为 `DOWN`。

## 6. 边界情况

| 情况 | 处理方式 |
|------|----------|
| 玩家在开关上停留不足 1 秒 | 取消触发，两块桥保持低位 |
| 第一块桥开始后玩家离开开关 | 两块桥继续按既定延迟完成上升 |
| 玩家在第二块桥启动前尝试通过 | 无法跨越仍处于低位的远端桥面 |
| 玩家误落到低位桥面 | 无法攀上出口，离开边缘后复位 |
| 玩家选择 `d1` | 沿下层折线路线正常通关 |
| 玩家选择 `d2` | 沿下层直线路线正常通关 |
| 玩家错误朝向进入 `E` | 不通关，可利用下层普通地形继续调整 |
| 玩家尝试接近装饰高台 | 被高差阻挡，装饰高台不形成玩法路线 |

## 8. 可调参数

| 参数 | 建议值 | 影响 |
|------|--------|------|
| `bridge_switch.holdDuration` | `1.00s` | 建立清晰的持续触发反馈 |
| `bridge_west.delay` | `0.00s` | 近端桥立即响应 |
| `bridge_east.delay` | `0.50s` | 形成可见但不拖沓的错峰 |
| `Elevator.moveDuration` | `1.25s` | 保持动画可观察，总等待不超过三秒 |
| 桥面上升距离 | `0.50` | 低位不可通行，升起后与主路线齐平 |
| 合法下落点数量 | `2` | 提供轻量路线选择 |
